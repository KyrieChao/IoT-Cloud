# 物联网云平台 APUE阶段项目


一个轻量级物联网云平台，APUE 阶段大作业，单人项目。

设备通过 TCP 接入云端，平台负责设备管理、远程监控和 OTA 升级。
后端网关用 C 写，管理台用 Flask，数据存 SQLite。设备端是真实硬件。

## 能做什么

- 设备接入：TCP 长连接 + JSON 行协议，DeviceID + Secret 鉴权，心跳保活
- 设备管理：设备列表、详情、禁用启用、设备影子
- 远程监控：遥测上报与展示、命令下发与响应、离线告警
- OTA：固件上传、任务下发、HTTP 下载、SHA256 校验、状态跟踪

## 大概长这样

```text
真实设备 ──TCP/JSON──▶ C 网关 ──▶ SQLite
                          ▲
                          │ HTTP
                       管理后台
```
